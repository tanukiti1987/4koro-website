# メニューPDFの生成方針

## 目的

`menu.pdf`は、店頭で配布したり家庭で印刷したりするためのA4縦1ページのメニュー表です。
Netlifyでは[`/menu.pdf`](/menu.pdf)として公開し、ブラウザで表示してから印刷できるようにします。
PDFは`Content-Disposition: inline`で表示し、価格改定後に再検証されるキャッシュ設定を
`netlify.toml`で指定しています。

## SSoT（唯一の編集元）

WebページとPDFの元データは[`data/site.yml`](../data/site.yml)です。次の情報をこのファイルで
管理します。

- 店舗情報、SEO情報、改定日、営業時間、売切案内、定休日
- 54商品の商品名、価格、単位、価格種別、Web説明、鮭入り（`salmon_included`）属性
- PDF用の短縮名（必要な商品だけ`flyer_name`を指定）
- `pdf_grid`に記載する商品IDの配置

生成された`dist/index.html`や`dist/menu.pdf`を直接編集しないでください。商品名や価格を
変更するときはSSoTを更新し、WebとPDFを同じビルドで再生成します。

## PDFの掲載範囲

PDFには次の情報だけを掲載します。

- 店舗名、改定日、電話番号、営業時間、売切案内、定休日
- お惣菜21商品とお弁当33商品、各価格
- 鮭入り商品を示す`★`、および税込み価格の注記

住所、商品説明、オードブル案内はPDFには掲載しません。これらの情報がWeb側に存在しても、
チラシの紙面へは流用しない方針です。

## 紙面設計

- A4縦、モノクロ、6列固定（商品名・価格の組を3組）
- お惣菜は3列×7段、お弁当は3列×11段
- 価格は各価格列で右寄せ
- 商品名列は左右9.0pt、価格列は左6.0pt・右9.0ptのpaddingとし、縦罫線と文字の間隔を確保
- 列幅は商品名・価格の実測文字幅にpaddingを加えて列ごとに算出し、さらに1ptの安全バッファを付ける。実測最小幅から生じる余剰は3つの商品名列へ均等配分し、惣菜・弁当とも表全体を正確に180mmへ揃える
- 最下部注記は罫線のない2列で構造化し、「★焼き鮭入り」を左端、「※税込み価格です。」を右端に配置
- 上下左右10mm以上の印刷安全余白
- Noto Sans JP Regular/BoldをPDFへ埋め込み、未埋め込みの代替フォントは使わない

現在の54商品を読みやすく収める設計値は次のとおりです。

- 表題：24pt前後
- 店舗情報：11pt、5行（改定日／電話番号／営業時間／売切案内／定休日）
- 商品名・価格：11.5pt程度
- 表の上下padding：8pt
- 現行PNGでの下余白：約19.5mm

これらは現行の商品数に対する読みやすさの基準値です。商品数が増えた場合に自動で文字を
小さくするための設定ではありません。

## 改行方針

表題と改定日の間に視認できる間隔を設けます。店舗情報は意味単位を分け、改定日、電話番号、
営業時間、売切案内、定休日をそれぞれ改行します。営業時間は`site.hours`のstart/endを日本語へ
変換し、現在は次の2行で掲載します。

```text
営業時間　10時から13時30分、16時から18時30分
※なくなり次第終了
```

## 収まらない場合の扱い

内容がA4 1ページに収まらない場合、ビルドは失敗します。自動縮小や2ページ化は行いません。
商品名をチラシ用に短くする場合だけ、対象商品に任意の`flyer_name`を指定します。配置変更は
`pdf_grid`に商品IDを記載して行い、商品名や価格を配置表へ複製しません。

## 生成と検証

全体を生成する場合は次を実行します。

```sh
python scripts/build.py
```

既存の`dist/`を残してPDFだけを再生成・検証する場合は次を実行します。

```sh
python scripts/build.py --pdf-only
```

ビルドは次を自動検証します。

- 商品ID、価格形式、区分、`pdf_grid`の未知・重複・欠落
- PDFがA4縦1ページで、54商品を一度ずつ含むこと
- PDF内のフォントがNoto Sans JP Regular/Boldとして埋め込まれていること

印刷レイアウトはPopplerでPNGに変換して目視します。

```sh
mkdir -p tmp/pdf-preview
pdftoppm -png dist/menu.pdf tmp/pdf-preview/menu
```

`tmp/pdf-preview/menu-1.png`で、文字切れ、文字や価格の重なり、黒い四角、罫線のずれ、
安全余白不足がないことを確認します。

- [ ] 価格改定時は`site.revision_date`も更新した
- [ ] `python scripts/build.py`を実行した
- [ ] `python scripts/build.py --pdf-only`でも検証した
- [ ] PDFをPNG化して紙面を確認した
- [ ] Webの価格とPDFの価格が同期していることを確認した
- [ ] Netlify Deploy Previewでビルドと表示を確認した
- [ ] `/menu.pdf`がブラウザ内表示（inline）され、再検証型キャッシュが有効になっていることを確認した
